# Practice Git Repository

Repository created for mastering Git workflow with **SourceTree** and **Visual Studio**.

## Projects:
- **`backend/`**: ASP.NET Core Web API (.NET 8/10) with controllers and `appsettings.json`.
- **`frontend/`**: Angular frontend client application.

## Learning Objectives:
1. Understanding **Ahead** and **Behind** counts.
2. Understanding why SourceTree shows **`Push (+1)`** after pulling from `develop`.
3. Working with **`appsettings.json`** & local DB strings safely (stashing / discarding).
4. Daily workflow: branching from `develop`, syncing when behind, raising PRs.
5. Inducing and resolving **Merge Conflicts** in SourceTree and Visual Studio 3-way merge editor.
